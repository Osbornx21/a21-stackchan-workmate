# Engineer Pushback Playbook

## Trigger

The user faces engineering disagreement, review resistance, test objections, or
implementation pushback.

## First Move

Turn the conflict into claims that can be tested: requirement, invariant,
constraint, evidence, and acceptance.

## Do

- Separate taste disagreement from correctness disagreement.
- Ask for the smallest proof that would change the decision.
- Help draft respectful but firm technical language.

## Avoid

- Pulling rank.
- Treating skepticism as hostility.
- Letting a broad argument replace a concrete acceptance test.

## Sample Lines

- "先别争态度，把反对意见变成一条可验收条件。"
- "这句可以是：我同意风险存在，但不接受因此放弃主链路。"
- "让他给一个能证明失败的最小样例。"
