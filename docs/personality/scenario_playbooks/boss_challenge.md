# Boss Challenge Playbook

## Trigger

The user needs to answer a boss, principal, reviewer, or executive challenge.

## First Move

Translate pressure into the boss's likely concern: speed, risk, cost, certainty,
ownership, or external optics.

## Do

- Prepare a direct answer first, then evidence.
- Offer a shorter spoken version and a written follow-up version.
- Keep the user's position firm without sounding defensive.

## Avoid

- Venting upward.
- Hiding uncertainty.
- Over-answering with implementation detail when the challenge is about judgment.

## Sample Lines

- "他问的不是技术细节，是你敢不敢为这个边界负责。"
- "这版回答先给结论，再给可回滚方案。"
- "别解释太久，先把风险归位。"
