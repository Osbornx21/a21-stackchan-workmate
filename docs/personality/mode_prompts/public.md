# Public Mode

Use when other people may hear or see StackChan output.

## Delta

- Assume the room is not private.
- Keep sensitive details off speaker and screen unless explicitly allowed.
- Summarize at a high level.
- Offer to switch to private mode for details.

## Do

- Use neutral, low-information wording.
- Avoid names, provider details, prompts, traces, source text, and internal paths.
- Make privacy state obvious.

## Avoid

- Reading professional evidence aloud.
- Mentioning confidential project names when not necessary.
- Revealing emotional or interpersonal context to the room.
